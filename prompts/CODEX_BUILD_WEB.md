# vividparachute 현재 제품 정의

웹은 PC·태블릿에서 읽는 개인 전과·복습 노트다. 사용자 질문은 Codex 프로젝트 채팅에서 처리한다. 웹 AI 질문, 별도 모델 API, 필기 도구, 문제 생성, 통계 대시보드는 구현하지 않는다.

좌측 원문 이미지 또는 개념 본문, 우측 관련 학습 기록을 읽는 단순한 화면을 유지한다. 현재 페이지 PDF 다운로드는 원본의 OCR 텍스트층과 최신 개념·질문·정리를 포함한다. 필기는 외부 PDF 앱에서 한다.

Codex 학습 저장은 docs/CODEX_STUDY.md, 배포·개인 자료 분리는 AGENTS.md와 README.md를 따른다. 이 정의가 시작 키트의 이전 웹 AI 채팅 요구사항을 대체한다.
