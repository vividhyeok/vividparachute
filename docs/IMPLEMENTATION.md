# 현재 구현과 검증

2026-11-23 사용자 수정 요구를 반영했다. 웹은 읽기와 PDF 내보내기 전용이다.

## 현재 동작

- PC·태블릿 가로에서 좌측 원문/개념 본문, 우측 학습 기록. 작은 화면은 세로 배치.
- 웹 AI 입력/모델 호출/정답 공개 토글/필기/편집 폼/검수 탭/통계 UI를 제거했다. 기존 개인 DB와 이력은 삭제하지 않았다.
- Codex 프로젝트 AGENTS.md와 사용자 스킬 `vividparachute-study`에서 원본 이미지+교정 텍스트를 읽고 질문에 답한다.
- `study context/record/sync/pdf/undo` 명령을 연결했다. 사용자 원문·Codex 답변·명시한 개인 기록·개념 본문은 분리한다. 버전 충돌은 거부하며 동일 entryId 재시도는 중복 저장하지 않는다.
- 개념 정리는 기존 본문과 통합한 완성 본문으로 저장한다. 기록 변경은 비공개 Blob에 게시하며 웹은 버전을 확인해 갱신한다.
- 원문 46문항, 61개 크롭. 크롭 경계 대조와 텍스트 검수를 구분한다. 상세 교정 완료는 2026 A 3번이며 45문항의 전사는 추가 검수가 필요하다.

## PDF

버튼을 누르는 시점의 저장 데이터를 조회한다. 원본 크롭은 한국어/영어 숨은 OCR 텍스트층을 넣은 PDF로 준비하고, 현재 질문·답변·메모·개념과 원문 텍스트를 새로 조판해 합친다. 개념 페이지는 본문·관련 기출·학습 기록을 포함한다. 한글(Noto Sans KR, OFL), 수식(KaTeX), 표·코드 글꼴을 포함한다. PDF를 평소 필기 앱으로 가져가 필기한다.

OCR 원문 PDF는 이미지 SHA로 캐시한다. 최신 복습 본문은 다운로드 시 재생성하므로 과거 정리로 고정되지 않는다. 원문 OCR의 오독 가능성은 남으며, 교정 텍스트는 별도로 제공한다.

## 배포 구조

공개 GitHub에는 코드·테스트·OFL 폰트만 올린다. 원본 PDF·이미지·개인 DB·전사 교정 전문·환경변수·내보내기는 Git에서 제외한다.

PC의 SQLite가 학습 원본이다. 원본 이미지와 OCR PDF를 PRIVATE Vercel Blob에 저장한 뒤 데이터 스냅샷 포인터를 교체한다. 배포 웹은 같은 스냅샷으로 두 화면을 읽는다. ETag 조건부 조회로 변경 없는 데이터 전송을 줄인다. PC가 꺼져도 마지막 게시본과 PDF를 읽는다. 웹 서버의 임시 디스크에는 학습 데이터를 저장하지 않는다.

사용자는 로그인 없이 바로 여는 공개 서재를 선택했다. Vercel Authentication을 사용하지 않으며 `VP_PUBLIC_READER=true`로 공개 읽기를 명시한다. 앱 서버가 PRIVATE Blob 파일을 읽어 공개 API/이미지/PDF로 제공하고 업로드 키는 노출하지 않는다. 별도 DB 서버는 없다. 로컬은 루프백 접근만 허용한다.

`npm run ship`은 의도한 origin/main을 확인하고, 개인 자료가 스테이징되면 중단한다. 소스 푸시는 Vercel Git 연결로 자동 배포한다. 새 학습 기록은 GitHub 커밋·재빌드 없이 `record` 명령이 비공개 저장소에 동기화한다.

## 검증 근거

- TypeScript 타입 검사 통과.
- 8개 테스트: 문항 조회·모호성, Codex 기록 분리·중복 방지, 버전 충돌과 원자성, 개념 전용 대화, 스냅샷과 현재 PDF 본문, 웹 AI 제거/읽기 전용, 실제 원문 SHA와 이미지, 접근 제어.
- Python 원문 분리 회귀 테스트 3개.
- 실제 2026 A 3번 PDF 생성, 원문 페이지의 선택 가능한 OCR 텍스트 확인. 한글 교정 텍스트 PDF 렌더링 확인.
- 격리 DB에서 질문·개념을 저장하고 개념을 보강한 뒤 `verification-current.pdf`, `verification-concept.pdf` 생성. 실제 개인 서재에 검증용 발화나 오답을 넣지 않았다.
- 의존성 audit 취약점 0개.

배포 빌드·태블릿 브라우저·실제 다운로드의 최종 결과는 이 작업의 완료 보고와 GitHub/Vercel 배포 상태를 기준으로 확인한다. Codex 스킬 자동 선택은 프로젝트 지침과 사용자 스킬로 설정했으며, 모든 과거 채팅을 감시하는 백그라운드 서비스는 아니다.
