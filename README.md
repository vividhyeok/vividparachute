# vividparachute

정보·컴퓨터 임용을 위한 개인 전과·복습 노트. 공부는 Codex에서 하고, 웹과 PDF로 다시 읽는다.

## 공부하는 방법

이 프로젝트의 새 Codex 채팅에서 `2026 A 3번 풀고 있는데 ReLU가 어디에 적용되는지 힌트만 줘`처럼 질문한다. Codex가 원문 이미지와 교정 텍스트를 확인하고 답한 뒤, 질문·답변 원문을 보존하고 유용한 지식을 기존 개념에 통합한다.

웹은 조용히 읽고 복습하는 서재다. 개념 전과와 기출·복습을 오가며 목차·검색과 현재 페이지 PDF 다운로드를 사용한다. 웹 AI 채팅, 모델 API 호출, 필기, 대시보드, 퀴즈는 추가하지 않는다.

## 전과와 복습 노트

**전과는 초등학교 참고서처럼, 흩어진 지식을 연결해 이해하도록 만든 개인 개념서다.** 상위 개념과 전체 구조를 먼저 잡고, 핵심 관계를 연결한 다음 이해와 문제 해결에 필요한 세부 사항만 담는다. 질문마다 지식 조각을 덧붙이거나 모든 디테일을 망라하는 바텀업 방식을 지향하지 않는다.

- **개념 전과:** 보편적인 정의·원리·관계·구분을 통합한다. 기존에 맞는 내용은 살려 다시 편집하고, 같은 개념을 중복 생성하지 않는다.
- **기출 우측 복습 노트:** 연결된 개념의 핵심 구조, 사례와 개념의 연결, 필요한 문제 적용을 간결하게 보여 준다. 사용자가 실제로 헷갈렸다고 말한 용어·차이는 굵게 강조한다.
- **내용에 맞는 형식:** 짧은 정의, 비교표, 수식, 코드, 화살표·흐름도, 필요한 예시를 선택한다. 블로그식 도입이나 길게 풀어 쓴 해설, 반복적인 문답 목록으로 만들지 않는다.
- **공부 노트 같은 화면:** 손글씨, 따뜻한 종이색, 옅은 공책 줄과 여백선, 절제된 밑줄·형광펜 강조를 사용한다. 코드와 수식은 전용 글꼴로 읽기 쉽게 유지한다.

전과 첫 화면은 **질문의 목적에서 출발하는 개념 지도**다. 현재 학습 내용을 바탕으로 `문제 읽기 / 의미와 구분 / 계산과 적용 / 동작과 순서`를 입구로 삼고, 각 개념의 첫 핵심 문장과 내부 목차를 함께 보여 준다. 개념을 선택하면 본문으로 이동한다. 개념 본문 우측에도 같은 길잡이가 있으며, 기출을 읽다가도 상단 `한눈에·검색` 또는 `/` 키로 펼칠 수 있다.

지도는 저장된 개념의 제목·별칭을 기준으로 묶고 본문에서 미리보기를 가져온다. 분류에 맞지 않는 개념은 `개념의 구조`에 표시해 누락을 방지한다. 개인 질문을 예측하는 추가 AI 호출이나 학습 통계를 만들지 않으며, 새 학습 기록은 기존 동기화로 지도에도 반영된다.

`기출·복습` 탭은 특정 문항이 아니라 연도·A/B형별 **기출 전체 목차**를 연다. 전체 목차와 `한눈에·검색`의 문항 번호에는 상태 색을 표시하고, 마우스 호버·키보드 포커스 시 `기록 없음 / 열어봄 / 공부 중 / 풀이 완료` 설명을 보여 준다. 각 번호 아래에 같은 상태 글자를 반복하지 않는다. 터치 화면에서는 ⓘ를 펼쳐 표시의 의미를 확인한다. 연결된 개념 설명이 있으면 번호에 밑줄이 생기고, 가장 최근 학습 기록이 있는 문항에는 작은 최근 표시와 이어보기 링크가 생긴다. 단순 열람이나 개념 편집으로 최근 학습 순서를 바꾸지 않는다.

`열어봄`은 해당 브라우저에 보관한 열람 기록이다. `공부 중`은 저장된 문항별 질문·메모 등의 기록에서 판단하고, `풀이 완료`는 사용자가 명시적으로 완료를 알린 경우에만 기록한다. 설명이 있거나 정답을 물었다는 이유로 완료를 추정하지 않는다. 기록이 없다는 표시도 실제로 풀어 본 적이 없다는 단정은 아니다. 웹은 읽기 전용으로 유지하며, 완료·재진행 상태 변경은 Codex의 학습 저장 과정에서 처리한다.

질문·답변 원문은 학습 원본으로 저장하지만, 웹과 복습 PDF에는 `질문과 정리` 또는 `Codex에서 정리한 내용`이라는 대화 목록을 나열하지 않는다. 화면에는 통합된 개념 노트를 표시한다. 사용자의 오답이나 생각을 추측해 만들어 넣지 않는다.

웹 손글씨는 눈누에서 찾은 [강원교육새음체](https://noonnu.cc/font_page/806)를 사용한다. 제작은 강원특별자치도교육청·헤움디자인이며, [제작처 사용 안내](https://open.gwe.go.kr/main/content.do?key=bTIzMDcyMTEyMDc3MTU%3D)에 따라 웹에 적용한다. 웹폰트는 눈누가 안내한 CDN에서 로드한다. PDF는 같은 손글씨 폰트를 서버에서 읽어 문서 안에 포함하며, 로드 실패 시 포함된 Noto Sans KR로 대체한다. 코드·수식에는 전용 글꼴과 한글 대체 글꼴을 유지한다. 폰트 원본을 공개 저장소에 추가하지 않는다.

`PDF 다운로드`는 기존처럼 현재 페이지를 내보낸다. 옆의 화살표를 열면 **전체 학습 노트 PDF**를 받을 수 있다. 별도 설정 화면이나 과목 분류 화면을 추가하지 않는다.

- **노트 서식:** 웹의 손글씨, 종이색·공책 줄·여백선, 형광펜 강조, 비교표·코드·수식을 인쇄용 A4 레이아웃으로 반영한다. 화면을 통째로 캡처하지 않으므로 한글 본문을 선택·검색할 수 있다.
- **기출 원문:** 원본 크롭과 숨은 OCR 텍스트층을 보존한다. 검색 가능함은 OCR의 완전한 정확성을 보장하지 않으며, 검수 상태를 유지한다.
- **전체 학습 노트:** 저장된 개념을 한 번씩 수록하고, 학습한 기출의 연결·메모와 검색 가능한 기출 원문을 묶는다. 아직 학습 기록·설명이 없는 기출 전체나 질문·답변 대화 목록은 자동으로 끼워 넣지 않는다.

내려받은 PDF에는 평소 필기 앱으로 필기하면 된다.

### 향후 PDF 선택 범위

과목별·영역별·기간별 선택 내보내기는 향후 방향이다. 현재는 정보·컴퓨터만 다루므로 과목 분류나 과목별 설정 UI를 미리 만들지 않는다. 추후 실제 과목·분류 데이터가 생기면 현재 페이지/전체 내보내기 흐름을 유지하면서 선택 범위를 확장한다. 지금 구현된 범위는 현재 페이지와 전체 학습 노트 두 가지다.

## 실행

Node.js 24 이상.

```powershell
npm install
npm run import
npm run dev
```

로컬 주소: http://127.0.0.1:3000

클라우드 읽기 주소: https://vividparachute.vercel.app (로그인 없이 바로 읽는 서재)

## Codex 연결과 동기화

```powershell
npm run study -- context "2026 A 3번"
npm run study -- record "data/private/inbox/entry.json"
npm run sync
npm run study -- pdf "2026 A 3번" "output/pdf/2026-A-3.pdf"
npm run study -- pdf all "output/pdf/study-notes.pdf"
```

프로젝트의 `AGENTS.md`와 사용자 스킬 `vividparachute-study`가 학습 절차를 지정한다. 입력 계약·버전 충돌·되돌리기·다른 프로젝트에서 쓰는 법은 [Codex 학습 안내](docs/CODEX_STUDY.md)를 참고한다.

로컬 SQLite가 학습 원본이다. 별도의 DB 서버는 없다. 저장 명령은 원문 발화와 개념 변경을 트랜잭션으로 보존하고 Blob 파일 저장소에 최신 스냅샷을 게시한다. 웹은 약 3초마다 버전을 확인한다. PC가 꺼져 있어도 마지막 게시본을 읽고 PDF를 내려받을 수 있다. 웹 서버가 로컬 디스크에 개인 데이터를 쓰지 않는다.


## 원문과 개인정보

실제 기출 46문항, 연결 이미지 61개. 크롭 경계는 원본 대조했고 `2026 A 3번`은 상세 교정했다. 나머지 45문항의 OCR·수식·코드·표 전사는 추가 검수가 필요하다. 검색 가능함이 전사의 완전한 정확성을 뜻하지 않는다.

- 공개 Git에는 앱 코드와 공개 라이선스 폰트만 보관한다.
- PDF·크롭·교정 전문·학습 DB·생성 PDF·`.env.local`은 Git에서 제외한다.
- 사용자가 선택한 공개 읽기 방식이다. 주소를 열면 기출과 개념·복습 노트를 로그인 없이 볼 수 있고 PDF로 내려받을 수 있다. 학습 원본의 질문·답변도 읽기 API와 JSON 내보내기에 포함되므로, 화면에 대화 목록을 표시하지 않는 것이 비공개 처리를 뜻하지는 않는다. 웹에서 내용을 수정하는 기능은 없다.
- 파일 저장소 자체는 PRIVATE Blob이며 앱 서버가 읽어 제공한다. 이는 별도의 비공개 DB 서버가 아니다. 업로드 키는 브라우저에 전달하지 않는다.
- `.env.example`은 이름 안내다. 실제 Blob 자격증명은 `.env.local`과 Vercel 서버 환경에만 둔다. 웹 AI 키는 필요 없다.
- 원본 백업: `data/raw`, `data/processed`, `data/private`, `overrides`의 개인 교정 파일. GitHub 커밋만으로 이 자료들이 백업되는 것은 아니다.
